# 대한민국 조양 임씨(兆陽 林氏) 가문 족보 & 글로벌 친척 지도 / Family Tree

대한민국 '조양 임씨(兆陽 林氏)' 가문의 생존 친척 인적 사항을 체계적으로 등록·보관하고, 세대별 **가계도 계통도(Family Tree Hierarchy)**와 **글로벌 거주 지도(Global Location Map)**를 통해 국내외 친족들의 소식과 뿌리를 한눈에 열람할 수 있는 고품격 모던 웹 애플리케이션입니다.

---

## 🌟 주요 핵심 기능

### 1. 친척 인적 사항 등록 및 부모 성명 연동
- **필수 입력 항목**:
  - `성명 (이름)`: 필수 입력 및 공백 검증
  - `이메일 주소`: 필수 입력 및 이메일 형식 유효성 검사
  - `부모 성명 (Parent Name)`: **가계도(Family Tree Hierarchy) 연결을 위한 필수/핵심 입력 항목** (기존에 등록된 친척 이름을 간편하게 선택할 수 있는 자동완성 datalist 지원)
- **자유 선택 항목**:
  - `거주 국가`: 대한민국, 미국, 캐나다, 일본, 호주 등
  - `거주 도시`: 7대 거점 원클릭 입력 버튼 지원 (전주, 용인, 토론토, 샌프란시스코, 버클리, 팔로 알토, 엘에이)
  - `전화번호`: 휴대폰 및 해외 유선 연락처
  - `자택 주소`: 거주지 상세 주소
  - `직장 (회사명/소속)`: 재직 중인 기업 또는 단체
  - `직책 / 담당 직무`: 직급 및 업무
  - `회사 주소`: 직장 소재지
  - `생년월일`: 양력/음력 생일 관리
  - `기타 항목`: 항렬, 가계 촌수 관계, 특이사항 및 덕담 메모

### 2. 가계도 계통도 수형도 다이어그램 (Family Tree Hierarchy)
- **부모-자녀 관계 기반 세대별 자동 수형도 연결**:
  - 선조(27대손 원로)로부터 28대, 29대, 30대(손자 세대)까지 깔끔한 가지선(Branch connector)으로 이어지는 계통도 다이어그램
  - 각 노드 카드에 가문 휘장, 성명, 세대(항렬) 배지, 거주 도시(7대 거점 왕관 배지), 직책 표시
  - 카드를 클릭하면 해당 친척의 전체 상세 프로필 모달이 즉시 팝업
  - **가계도 전용 컨트롤**: 확대(Zoom In), 축소(Zoom Out), 초기화(Reset View), 가계도 내 실시간 이름/도시 검색 및 하이라이트

### 3. 한글 / 영어 (KO / EN) 원클릭 전환 토글 스위치
- 상단 헤더 우측의 `[🇰🇷 KO / 🇺🇸 EN]` 토글 스위치로 전체 사이트 언어를 원클릭으로 즉각 전환
- 메뉴, 통계, 7대 거점 설명, 지도 팝업, 가계도 라벨, 명부 표 머리글, 등록 모달 라벨, 알림 메시지까지 완벽 번역 지원
- 선택한 언어는 브라우저(LocalStorage)에 자동 저장되어 다음 방문 시에도 유지됩니다.

### 4. 가문 7대 거점 특별 돋보임 (Spotlight Hubs)
- 가장 많은 친척들이 거주하는 핵심 7대 도시를 상단에 황금빛 배지 카드로 강조:
  - 🇰🇷 **대한민국 전주**: 가문의 뿌리와 종친회 본관 중심지
  - 🇰🇷 **대한민국 용인**: 수도권 친족 밀집 집성촌
  - 🇨🇦 **캐나다 토론토**: 캐나다 동부 교민 네트워크
  - 🇺🇸 **미국 샌프란시스코**: 미 서부 베이 에어리어 금융/문화 허브
  - 🇺🇸 **미국 버클리**: UC 버클리 및 학술 연구 인맥
  - 🇺🇸 **미국 팔로 알토**: 실리콘밸리 테크 및 스탠퍼드 연구진
  - 🇺🇸 **미국 엘에이 (LA)**: 미국 최대 한인 사회 및 남가주 종친회
- 거점 카드를 누르면 지도 카메라가 해당 도시로 부드럽게 비행(Fly)하며, 해당 지역 거주 친척 목록이 즉각 필터링됩니다.

### 5. 인터랙티브 가문 지도 (Leaflet.js)
- 전 세계 및 국내를 한눈에 볼 수 있는 인터랙티브 지도
- 7대 주요 거점에는 **황금빛 펄스 애니메이션 마커와 가문 문장(林)** 적용
- 마커 클릭 시 해당 도시 거주 친척 명단 팝업 및 바로가기 제공
- 빠른 시점 전환: `[전세계 조망]`, `[대한민국]`, `[북미(미국/캐나다)]`

### 6. 어르신 맞춤형 글자 크기 3단계 토글 (Senior Accessibility)
- 상단 헤더의 원클릭 폰트 스케일링 버튼:
  - **보통 (100%)**: 표준 데스크톱/모바일 크기
  - **크게 (125%)**: 노안이나 작은 글씨가 불편하신 어르신 추천 모드
  - **아주 크게 (150%)**: 고대비와 대형 폰트로 매우 시원하게 열람
- 선택한 글자 크기 설정은 브라우저(LocalStorage)에 자동 저장되어 유지됩니다.

### 7. 데이터 영구 보관 및 백업/내보내기
- **자동 저장**: 브라우저 로컬 저장소(LocalStorage)에 실시간 자동 동기화
- **엑셀(CSV) 저장**: Excel에서 한글 깨짐이 없는 UTF-8 BOM 형식의 CSV 명부 다운로드 (부모 성명 열 포함)
- **JSON 백업/복원**: 다른 가족의 PC나 스마트폰으로 전달하거나 영구 보관할 수 있는 파일 입출력

## 📁 파일 구조

```
Family Tree/
├── index.html          # 메인 웹페이지 (반응형 단독 실행 SPA)
├── css/
│   └── style.css       # 럭셔리 클랜 테마, 가계도 수형도, 폰트 스케일링, 언어 토글 스타일
├── js/
│   ├── i18n.js         # 한국어(KO) 및 영어(EN) 번역 사전
│   ├── data.js         # 7대 거점 좌표 사전 및 부모-자녀 계통이 반영된 샘플 데이터 (14명)
│   ├── map.js          # Leaflet 지도 제어 및 황금 펄스 마커 모듈
│   ├── tree.js         # 가계도 계통도(Family Tree Hierarchy) 수형도 렌더링 엔진
│   └── app.js          # 폼 검증, 부모 성명 연동, 언어 전환, CRUD 및 백업 모듈
└── README.md           # 본 안내 문서
```

## 🚀 실행 방법

별도의 서버 설치나 복잡한 명령어 없이, **`index.html` 파일을 더블 클릭하여 크롬(Chrome), 엣지(Edge), 사파리(Safari) 등 웹 브라우저에서 바로 실행**하실 수 있습니다.
가족 및 친척분들에게 폴더 전체를 전달하시거나, 웹 호스팅(GitHub Pages, Vercel 등)에 업로드하여 전 세계 친척들이 함께 접속하도록 운영하실 수 있습니다.
